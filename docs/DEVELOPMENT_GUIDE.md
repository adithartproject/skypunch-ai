# Commit Message

Gunakan format:

feat:

Fitur baru.

fix:

Perbaikan bug.

docs:

Dokumentasi.

refactor:

Perbaikan struktur kode.

test:

Testing.

chore:

Pekerjaan pendukung.

Contoh:

feat: add flutter generator

docs: update roadmap

fix: login validation
